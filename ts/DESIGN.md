# DESIGN.md — dc-ts 界面规范

来源：`.oil-ui/dc-redesign/v6.html` 的「控制墙」方向，落地到 `ui/src/styles.css`。所有值以 CSS 变量为准，本文只做索引与规则说明。

## 设计变量（`styles.css` 的 `:root`）

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` / `--panel` | `#08090A` / `#0D0F0E` | 页面底 / 面板底 |
| `--tile` / `--tile-2` | `#101312` / `#141817` | 卡片、格子的上下渐变 |
| `--line` / `--line-2` | `#1C201E` / `#141816` | 主分隔线 / 行分隔线 |
| `--fg` / `--fg-2` / `--fg-3` / `--dim` | `#EDEEEA` / `#A6ABA3` / `#757B72` / `#4E544B` | 正文四级灰阶 |
| `--green` | `#3FBF86` | 运行中、成功 |
| `--amber` | `#E0A94A` | 可更新、主操作 |
| `--red` | `#C7563F` | 已停止、删除 |
| `--mono` | 系统等宽栈 | 所有数字、镜像名、cron |
| `--sans` | 系统中文字体栈 | 名称、文案 |

规则：

- **状态色只有三处**：状态灯（绿/红）、可更新标记与主按钮（琥珀）。其余一律用灰阶。
- **数字必须等宽**（`.num`），并右对齐；单位用小一号的 `--fg-3`。
- 圆角只用 `2/3/4px`；不加阴影（除浮层 `toast`、`sheet`）。
- 动效只允许 `transform`/`opacity`，时长 120–150ms，不允许发光脉冲。

## 布局与断点

```
.app  = 侧边轨 54px + 内容
.shell（仅容器页）= 主区 1fr + inspector 356px
```

| 断点 | 变化 |
|---|---|
| `> 1240px` | inspector 356px |
| `1024–1240px` | inspector 320px |
| `< 1020px` | inspector 隐藏；点格子从底部弹出 `.sheet`（高 76vh，含 `.backdrop`） |
| `< 760px` | 侧边轨隐藏；容器墙 2 列；表格 `.phead` 隐藏、行改三列；Compose 项目列表横向滚动 |

## 组件

| 组件 | 类名 | 说明 |
|---|---|---|
| 容器格子 | `.tile` / `.tile.upd` / `.tile.sel` | 状态灯、名称、镜像、CPU/内存双条、运行时长或更新按钮 |
| 详情面板 | `.panel`（`.insp` / `.sheet` 共用） | 标题区、KPI、镜像 digest、运行信息、操作按钮 |
| 列表 | `.ptable` / `.phead` / `.prow` | 镜像与备份共用；行高 52px |
| 表单 | `.form` / `.field` / `.check` | 设置页；字段说明用 `<em>` |
| 编辑器 | `.compose` / `.ctext` / `.cout` | Compose 页，输出区等宽、可滚动 |

## 状态与交互

- 格子：hover 上浮 1px + 边框提亮；选中 `.sel` 左侧 2px 绿轨；可更新 `.upd` 左侧 2px 琥珀轨 + 琥珀按钮。
- 操作按钮默认 62% 透明，hover/focus 变实；危险操作（删除镜像/备份）用 `.danger`。
- 反馈：所有异步操作走 `toast`（2.4–2.6s），更新任务把最新一步实时显示在 toast 上。
- 键盘/无障碍：导航用 `aria-current`，抽屉关闭按钮有 `aria-label`。

## 文案

- 名词统一「容器 / 镜像 / 备份 / Compose / 设置」。
- 按钮用动词短语：「拉取并重建」「一键生效」「恢复」「删除」。
- 不在界面上写「示例」「未接入」这类制作说明；未实现的能力直接不出现。
